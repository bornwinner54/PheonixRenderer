# PhoenixRenderer

A modern real-time rendering engine written in C++ and OpenGL.

The goal of PhoenixRenderer is to create a cinematic real-time short film,
"The Journey of a Flame", entirely rendered in OpenGL.

Current Version

v0.4 Transform System

Current Features

✓ Win32 Window
✓ OpenGL Context
✓ Shader System
✓ Vertex Buffers
✓ Vertex Arrays
✓ Mesh Rendering
✓ Timer
✓ Transform System
